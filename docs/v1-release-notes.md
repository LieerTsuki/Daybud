## 本版行为

- “计划／打卡／订阅／设置”四入口；待办与日程统一为同一条计划，加日期保留ID，可完成／撤销；重复日程完成表示整个系列结束。
- 计划筛选、详情／编辑、月周日日历和独立全库统计；草稿、通知和维护操作保留原世代与一次消费保护。周日为按日列表，不含小时拖拽时间轴。
- 显式1–5→6数据库迁移保留来源映射、父子／标签／例外、习惯和订阅历史；不使用destructive migration，不支持降级数据库。

- 本轮修正通知Intent与生命周期跟踪、两处48dp布局，并补齐真实Activity操作／草稿旋转／严格通知设备回归。

1. 在旧版设置导出完整备份，另存到可信位置并保留原文件。备份为明文，SHA只检测完整性，不提供加密或身份认证。
2. 同签名APK可尝试覆盖安装；本轮在独立API35 AVD用旧发布APK和完整十表合成数据实际验证。真实用户设备及厂商系统仍需专项验收。
3. 签名冲突时保留旧应用和备份，先核对证书／包来源；不要直接卸载或清数据处理。已经升级到schema6的设备不安装旧0.1.1降级；只能向前修复或在V1中恢复经验证的备份。
4. V1文件中的旧待办不含时区；预览将明确显示恢复设备使用的时区。V2不支持导入旧版应用。超64MiB/100,000总行或不合法文件拒绝，不截断。
