# 手机离线AI实施计划

基线：f1367b8，正式1.2.1/code13，已有1295项JVM和79项API35设备回归通过。2026-10-20用户确认离线设计，后续发布采用新版本，不覆盖既有Release。实施分支feat/offline-diary-ai；最终沿用项目main推送流程。

## 必须实现的结果与关键接线

| 可观察结果 | 组件 | 接线 |
| --- | --- | --- |
| 没有Key也能选择手机离线，模型可准备并持久保留 | LocalModelStore、LocalModelCatalog、LocalDeviceCapability、AI设置页面 | 页面文件选择/下载→有界临时文件→摘要校验→原子就绪模型 |
| 切换离线后后台不再上传日记，重启也有效 | AiServiceConfig本地类型、RoutingAiStateStore、DiaryAiEngine | 选择模式→持久路由修订/暂停授权→每次发送前guard |
| 真正断网生成五段日记回顾，来源检查仍有效 | NativeLlama、LocalCompletionGateway、进程服务与客户端 | DiaryAiEngine→离线路由→私有推理进程→llama.cpp CPU→结构/来源校验→显式保存 |
| 长材料不因字符预算绕过token限制，不丢来源 | 本地分词/分段/汇总策略 | 实际token计数→有界分片→层级汇总→完整来源集合核对 |
| 卡住、取消和推理进程退出均可恢复操作 | 进程会话、客户端取消、ViewModel状态 | 用户取消/失联→停止会话/释放资源→无残缺保存 |
| 原日记/备份/提醒不被推理进程误改 | LifeManagerApp初始化隔离、Manifest私有服务 | 推理进程不获取业务依赖图/Room/媒体回收；主进程仍拥有维护保护 |

## 有序任务

1. 固定底层版本与合同。原生负责人核实llama.cpp接口、NDK/CMake、API26与16KiB；模型负责人核实小模型发布源/摘要与导入合同；本地管线负责人核实进程边界和token合同。父代理统一接口，不并发修改同一文件。先取得最小真实推理证据，未通过不能用假输出继续宣称完成。
2. RED测试。增加云端/离线模式切换失效和自动授权暂停、保留云端配置及重启路由、HTTP错误分类、模型原子导入/损坏/取消、本地预算/来源保持/进程失联等有意义测试；在缺失能力的基线上观察失败并保存日志。新增接口可先建立最小定义，行为仍须红测试证明。
3. 分开实现底层与模型管理。NativeLlama及CMake只由原生负责人改；LocalModelStore/Catalog/Capability只由模型负责人改；推理网关、私有进程和token策略只由管线负责人改；父代理负责配置、引擎、依赖注入、应用初始化、Manifest及UI。
4. 集成模式与页面。优先保留旧构造参数和默认云端行为，使旧测试/用户配置继续工作；本地配置不伪造HTTPS或Key。设置页面提供模型准备、删除、检查和模式切换；回顾页面按实际模式显示说明与阶段，支持取消。云端自动授权只在明确云端模式可开启。
5. 本地推理与保护验证。真实GGUF和原生库运行合成中文日记，检查五段结果、来源及断网生成；核对取消、资源不足、进程启动不触发业务维护、切换与重启Worker不上传。模拟器验证如实限定为模拟器，ARM真机未获得时不宣称大多数机型适配。
6. 全量验证与独立审查。串行运行Gradle JVM、AndroidTest、Debug/Release和lint，避免多个Gradle进程争用；新增逻辑通过后再跑一次全量。核对所有原生库ABI/16KiB和签名矩阵，真实覆盖升级保持Room8/备份V4和已有数据。失败先定位后修正，保留失败轮日志。
7. 文档与交付。同步CHANGELOG、README、架构、代码索引、验收、许可证和实际限制。经签名、源码/包摘要和升级核对后推送main并发布新版；匿名回下载APK校验，记录正式发布回执。离线功能的成熟度按真实硬件证据标记，不能把模拟器结果写成真机适配。

## 验证方式

- 单元/Room/UI回归覆盖模式、范围、来源修订、保存、模型文件完整性、预算和取消；使用真实临时文件，不只镜像实现。
- 原生推理设备验收使用固定哈希模型和合成材料；至少记录实际库/模型版本、运行环境、耗时和输出校验，不运行用户私有日记。
- 新旧配置兼容、后台授权、推理进程隔离、API26/28/35安装/回归和16KiB作为集成门槛。
- 真实手机性能与覆盖率必须由对应设备实测支撑；缺少设备时发布说明明确仍待验证，不伪造证据。

## 风险与回退

主要风险是轻量模型中文质量不足、低内存杀进程、JNI跨ABI构建、模式与Worker竞态及模型下载失败。使用固定模型/原生版本、独立进程、真实token预算、单任务和原子文件降低风险；不通过时收缩支持范围，不减弱来源和备份保护。

回退以代码分支/新增提交完成，不降级已安装数据库、不卸载或清数据、不撤销历史Release。既有1.2.1 APK始终保留；不可在未验证时把半成品替换正式最新版。
