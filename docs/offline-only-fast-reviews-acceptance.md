# 纯手机离线总结与建议：实施验收进度

日期：2026-10-22。分支：`feat/offline-only-fast-reviews`。基线为已发布1.3.0/code14，源码 `1d6afb48fd0b2304c52328d7faccfe9733355ad4`。本轮为开发实现，版本号未变，无新公开 APK 或 Release；不能使用旧版的测试数字代替本轮验证。

后续状态：用户在获知本文件中的限制后明确要求发布，现另行准备1.3.1-preview/code15测试版，见[测试版发布验收](offline-only-preview-1.3.1-acceptance.md)。下文保留开发阶段的质量失败和速度待测结论，不能改记为通过。

## 已接线的开发实现

- GGUF目录采用最多64KiB的读取窗口，保留每次完整大小、SHA256、元数据、张量边界与只读FD检查。导入仍读取用户选中的文件，不会转成下载。
- 生产生成依赖只接入手机模型。离线配置独立存储，旧云端密钥损坏不阻塞选择；旧AI周期工作退役并定向取消，清理专用旧凭据，不触及其他提醒和业务数据。
- 新 `phone-summary:v1:<模型SHA256>` 协议一次传入全部有效来源，最多16篇，输入/输出按真实token和字节预算拒绝过长材料。不再强制按8篇分批，不静默删减来源，不自动换模型或重试。
- 生成短总结与两条建议，心情及来源由程序生成；页面显示真实阶段、已用时间和取消。旧摘选与旧云端回顾继续按历史格式展示。
- Engine与Room分别校验新协议，核对完整来源、模型标识和输入摘要；生成正文保存收据防止后续篡改，源修订、数据世代和配置变化拒绝旧动作。保存的配置准入与模型切换串行，整段推理不持该锁。
- Room8、备份V4、包名、已有模型文件及历史回顾格式未变。ARM dotprod 候选独立构建、独立基线探测，首次JNI解析前只选择一种完整引擎；默认不编译/打包/启用额外候选。

## 当前验证与限制

局部红绿测试已覆盖缓冲边界/EOF/跳读、损坏模型和真实模型获取、超时类别、旧云端退役、真实WorkManager定向取消、完整来源/正文收据、模型切换并发及维护准入。局部日志保留于仓库忽略目录 `.tools`，整合结果另行更新，不能把局部数字相加冒充全套通过。

本轮完整Gradle验证通过：149套件、1462项JVM测试，failure/error/skipped均为0；Debug与androidTest APK构建成功，lint为0错误/34警告。真实Room混合旧云端、旧摘选与新总结完成V4清单往返、清空/恢复、旧快照拒绝及删除来源级联检查。

API35 x86_64模拟器（4GB RAM、2核心）上5项真实JNI/Binder结构运行测试通过：加载/分词、完整来源与真实结束标记、取消、精确私有推理进程死亡后恢复、Engine显式保存。另1项唯一引擎加载测试通过；初次测试因直接从APK映射原生库而漏判，已改为按ZIP条目偏移核对实际映射，再次执行通过。Debug APK的16KiB zipalign检查通过，确认默认包未包含dotprod候选。

三篇合计1135汉字的Engine生成一次观测为53234ms；两篇短材料为14157ms；取消为5ms。使用已准备好的模型，每次仍执行获取/校验及运行会话；不是三次冷启动统计，期间另有构建工作，不宜横向对比旧版数字。输出实际出现跨天概括不准、建议以逗号结尾等内容问题；5项测试只通过结构/运行门槛，**不是内容质量通过**。[本轮验证汇总](evidence/offline-only-fast-reviews-20261022-validation.json) · [实际输出与阶段记录](evidence/offline-only-fast-reviews-20261022-runtime.json)。

同一独立API35模拟器的79项其他业务设备回归全部通过，未使用connected任务卸载/清空应用。默认Debug APK内8个日记原生库的ELF LOAD段均满足16KiB对齐；[原生构建与APK证据](evidence/offline-only-fast-reviews-20261022-native.json)。尚无Pura 70或其他ARM真机测速；dotprod构建/ELF检查不能证明手机速度或覆盖率。30秒仍是设计目标。

内容质量**未通过**：初期63次桌面探索之外，实施协议又运行48次固定语法的Qwen3合成测试，仍有把计划写成结果、误述时间、遗漏多天材料等问题。另下载并校验官方Qwen2.5 1.5B Q4候选，只运行4组筛查就发现跨天误述及建议不够具体；未加入手机模型目录，也未要求用户下载。[原始输出与失败记录](evidence/offline-only-fast-reviews-20261022-summary-quality.json)。所有材料为人工合成，无用户日记。

JSON完整、结束标记和结构检查均不能证明语义正确。当前没有任何候选获准替换正式APK中的生成协议，也不能宣称“多数手机快速生成”。依据用户已确认的设计门槛，先保留开发分支，不发布声称修复的正式版本。
