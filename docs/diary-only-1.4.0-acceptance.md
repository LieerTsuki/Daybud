# 1.4.0 普通日记版验收

日期：2026-10-22。版本：1.4.0/code16。状态：本轮验证通过，尚未发布。

按用户“关于AI日记的功能全部不要了，只需要日记”的要求，移除AI回顾/设置、云端与本地生成、模型下载/导入、推理服务/进程、原生引擎和INTERNET权限。计划、打卡、订阅及普通日记继续保留；不是整个应用只剩日记。

普通日记继续支持文字、日期、心情、照片/视频、自动保存草稿、列表/日历、倒序、连续记录、本月统计及那年今日。去掉与AI相关的导航状态和Activity所有者，日记可独立创建，不依赖AI配置或模型。

## 数据与升级边界

- 使用更高版本号覆盖1.3.x，不安装旧版降级，不卸载或清数据库。包名、正式签名轮换链、Room8和备份V4保持。
- 历史回顾的存储类型及数据表仅为旧备份兼容保留，不提供回顾页面或生成入口。旧云端/原文摘选/短总结记录可在备份中往返，源日记删除级联仍由仓库负责。
- 仅保留两个退役兼容类：旧Worker返回成功并定向取消旧AI周期工作；旧专用凭据清理不解密、不联网。已导入的模型不再读取；本次不自动递归删除用户已有私有文件。
- 备份恢复/清空已解除对AI设置的依赖，仍使用现有维护准入、世代、草稿、媒体租约和Room事务保护。

## 验证记录

先以已发布1.3.1-preview APK执行`tools/verify_diary_only_apk.py`，确认出现5类失败：联网权限、AI服务进程、原生库、模型许可证资产和活动AI类。新包需全部消失。

真实Activity回归保留普通日记写入、切页、旋转和完成的保护，并增加日记及设置入口无AI按钮断言。真实Room/V4混合历史回顾测试改为直接使用保留的历史数据类型，不再依赖已删除的生成引擎。本轮重新执行 clean、Debug/androidTest/Release 构建及 Debug/Release lint，整体成功。1269项JVM测试（120套件）和77项API35设备测试通过，failure/error/skipped均为0；17项签名工具测试通过。Debug/Release lint均为0错误、23条警告。Debug、未签名Release与最终签名APK均通过包边界检查；正式签名六个SDK检查点与16KiB对齐通过。API26/28/35从1.3.1-preview/code15覆盖到1.4.0/code16均通过：23张表的列/值/类型/NULL/序列、Room身份、UID和有效签名保持。现有AVD只有三条默认行，业务为空；非空日记/草稿/附件与旧回顾往返由独立Room/V4与设备测试覆盖。API26首次在安装前快照时ADB返回255，未执行安装；保留该失败记录，确认仍为旧版后重新完整准备并验证成功。[本轮完整验证](evidence/diary-only-1.4.0-validation.json)。

AI专属实现和其过时生成/模型测试一并删除，保留仍有效的历史兼容/退役测试；测试总数应按本轮报告重新统计，不能沿用1462/85等旧数字。
